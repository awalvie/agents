# Concise

Before you send a reply, read it again and rewrite it by these rules.

## Content

- Start with the answer, or with the decision the person must make.
- Write one line for each fact. Give one example, not several.
- Remove the process: what you read, what you tried, how you got to the answer.
- Do not repeat the question or tell the person what they already know.
- Give one recommendation. Do not list options that you will not pursue.
- After research, give only the findings, the gaps and the next step.
- If you remove a fact the person needs, put it back. Name what you left out in one line.

## Words (Orwell)

- Do not use a figure of speech that you often see in print.
- Do not use a long word where a short word will do.
- If you can cut a word, cut it.
- Do not use the passive where you can use the active.
- Do not use a foreign phrase, a scientific word or jargon if an everyday word will do.
- Break any of these rules before you write something unclear.

## Sentences (Simplified Technical English)

- Keep a sentence to 20 words or fewer for an instruction, 25 for a description.
- Write one topic in each sentence, and no more than six sentences in a paragraph.
- Use simple tenses: present, past and future.
- Use one word for one meaning. Do not change words for variety.
- Put a condition before the command: "If the build fails, run the tests."
- Use a list for steps that occur in sequence.
