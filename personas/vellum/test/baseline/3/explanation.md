# Three directions for the bookshop events site

Each file shows the home page and one event page (Mara Lindqvist's reading, the "only a few seats left" case) side by side in phone frames, because most visitors arrive on a phone from a social post.

## Direction 1: Shelf talkers

Every event is a handwritten-style recommendation card clipped to a kraft-paper shelf, like the cards booksellers write for books they love. The event type sets the card colour and a line doodle, and a rubber-stamp label answers cost and booking ("Free, just turn up", "£5, only 6 seats left", "Sold out, join waiting list"). The event page leads with a staff quote in handwriting, so the owners' own voice becomes the main piece of personality. It is the warmest and most like the shop.

Tradeoff: the charm comes from rotation, handwriting and texture. These cost legibility and space on a small screen, and they can look twee if the owners' writing is flat. The handwritten font is for short accents only; it will not work for long text.

## Direction 2: The Almanack

The site is the shop's printed monthly programme, set in type with one spot colour. The home page is a dated list with a printed key (open circle = free, no booking; filled circle = book a seat; cross = sold out) and seats left in the right column. It has the most events on one screen and is the fastest to scan for "what, when, how much". The event page puts the facts in a "Particulars" table and has the booking form on the page, so booking takes the fewest steps. It needs no images at all, and the eccentric part is in the wording and the ornaments.

Tradeoff: it is the least eye-catching of the three. A text-only page does not stand out when someone taps through from Instagram, and the key symbols must be learned, although each row also says the answer in words.

## Direction 3: Event jackets

The site draws a book jacket for each event from its type (colour and pattern) and its title (lettering). This solves the no-photography requirement in a way that still looks like artwork. A coloured band across the top of every jacket answers "can I get in?". The event page repeats that answer in a four-cell grid (when, cost, getting in, where) and in a sticky bar. Below the phones, a strip shows how the bar changes for free, bookable and sold-out events. The owner picks one of these three settings and the site writes the words.

Tradeoff: it is the strongest visual identity, and a jacket also works as the image for social posts. But the cover grid shows only about four events per screen, and the look is more graphic and modern than cosy. The jackets also need the owners to use the same event types every time, or the colour system stops meaning anything.
