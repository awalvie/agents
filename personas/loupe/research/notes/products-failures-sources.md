# Sources

All accessed 2026-09-25 unless noted.

**How each source was read:**
- **FULL** = I read the primary text myself (the page, or the PDF rendered and read by me).
- **VERBATIM** = I asked the fetch tool for verbatim quotes of specific passages.
- **SUMMARY** = I saw only a fetch-tool summary of the page. The tool fabricated one summary (Iacovides et al.), so SUMMARY-only numbers are less secure.
- **QUOTED** = I did not read the source itself; I only saw it quoted in search results or in another source.

Tier follows the brief: T1 = primary/authoritative, T2 = professional, T4 = community.
